# HAGEN Official Website

A complete static band website built with plain HTML, CSS, and JavaScript.

## Files
- index.html - page structure/content
- style.css - design, responsive layout, animation
- script.js - menu, particles, scroll reveals, demo player, contact form

## Run locally
Open index.html in a browser.

For a local server, from this folder run:
  python -m http.server 8000

Then visit:
  http://localhost:8000

## Before publishing
1. Replace placeholder streaming/social links in index.html.
2. Replace booking@hagenband.com with the band's real email.
3. Replace the placeholder artwork with your real Hagen logo/album art.
4. Add real MP3/audio URLs to the player if desired.
5. Update the shows and merch sections.

This is a static site, so it can be hosted on GitHub Pages, Netlify, Vercel, Cloudflare Pages, or most normal web hosts.
